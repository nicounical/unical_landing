# Higgsfield — storyboard y prompts (no generado)

Higgsfield se usa como **referencia de lenguaje de cámara**. Los efectos web están hechos con GSAP/CSS. **No se ha generado ningún vídeo.** Hay integración disponible, pero consume créditos y requiere tu aprobación.

**Regla:** nada generado se presenta como trabajo real de Unical. Solo sirve para transiciones, texturas o fondos abstractos, o como guía de rodaje.

## Movimientos aplicados en la web
| Movimiento | Dónde |
|---|---|
| Dolly-in | Portada A (zoom de la escena al hacer scroll), Proyectos E |
| Orbital | Portada B (órbita de proyectos) |
| Reveal / transformación | Portada C (de plano vacío a stand iluminado) |
| Zoom dramático a través de máscara | Portada D (el punto de «B2B.» se abre al vídeo), Reel A (círculo) |
| Parallax multicapa | Portada E, Reel D, Proyectos B |
| Motion blur / velocidad | Servicios C, Sectores E, Clientes E (inclinación y aceleración con la velocidad del scroll) |

## Prompts propuestos (para transiciones, no para «proyectos»)
